# Store asset provenance and accessible descriptions

The icon and feature graphic are deterministic SVG source files rendered locally with macOS `sips`; they extend the existing deep-soil, gold pillar, and single-sparkle launcher identity. They contain no generated bitmap artwork.

- `icon.svg`: gold standing pillar/figure in a deep-soil circle, with one restrained four-point sparkle.
- `feature-graphic.svg`: warm paper banner with an abstract gold standing silhouette, a gold timer ring, and a single sparkle; it intentionally contains no health values or claims.
- Phone screenshots: captured from the actual debug phone app on `zhan_zhuang_task10_phone_api36` (Pixel 8, Android API 36) at native emulator viewports; duration, interval, history, and privacy are real app states. The bilingual settings captures are 1080×2160, with the app locale asserted before capture.
- Wear screenshots: captured from the actual debug Wear app on `zhan_zhuang_task10_wear_api33` (`wearos_large_round`, Wear OS 4 / API 33, 454×454); setup and heart-rate-permission/duration-only states contain no invented live heart-rate values. The setup and permission labels were asserted from the rendered UI before capture.

Fastlane Supply has no alt-text upload field for these Play listing assets. Keep this sidecar with the source assets for console accessibility review.
