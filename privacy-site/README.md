# 站桩 · Zhan Zhuang privacy site

Public bilingual privacy policy for the Android and Wear OS apps with package
name `app.zhanzhuang.timer`.

## Commands

- `npm run dev` starts the local preview.
- `npm test` builds the site and verifies the rendered policy and palette.
- `npm run lint` runs the source checks.

The deployed page contains no account flow, forms, analytics, advertising,
database, or user-data storage.
